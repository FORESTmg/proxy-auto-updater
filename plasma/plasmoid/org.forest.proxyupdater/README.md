# Плазмоид панели KDE — значок FOREST's Proxy Auto-updater

Виджет для **KDE Plasma 6**: иконка программы в панели, по правой кнопке
открывается **наше меню** (`forest-ui --menu-popup`) — с нашими цветами,
анимацией и подменю, а не меню панели.

---

## ⚠️ Прочитайте до добавления виджета

1. **Добавляйте виджет только из этой версии пакета.** В первом выпуске 1.3.2
   плазмоид запускал внешний процесс из QML по таймеру каждые 5 секунд
   (модуль Plasma 5 `Plasma5Support.DataSource` с `engine: "executable"`). На
   живом сеансе CachyOS (Plasma 6, Wayland) это **подвесило оболочку**: панель
   перестала отрисовываться и реагировать на клики.
2. **Если вы уже добавили виджет из того выпуска — удалите его** до обновления:
   правый клик по панели → «Войти в режим правки» → наведите на значок FOREST →
   значок удаления (или «Удалить виджет»). В новом пакете плазмоид переписан:
   процессов он больше не запускает вообще.
3. Виджет — **необязательная** часть. Сама программа (служба, прокси, значок
   `forest-ui` в трее) работает и без него.

---

## Зачем он нужен

В Linux два механизма трея:

* **XEmbed** (XFCE, MATE, Cinnamon, LXQt) — правый клик по значку доставляется
  программе, и `forest-ui` сам показывает наше меню. Плазмоид там не нужен;
* **StatusNotifier** (KDE Plasma, GNOME с AppIndicator) — правый клик забирает
  САМА панель: она запрашивает у программы описание меню по D-Bus и рисует его
  своим стилем. Наше окно она не видит никогда — это ограничение протокола.
  Плазмоид закрывает разрыв: он рисует нашу иконку в панели и по клику открывает
  `forest-ui --menu-popup`, то есть наше меню.

## Установка

Отдельный пакет НЕ нужен: плазмоид ставится вместе с основным пакетом
`forest-proxy-updater` в `/usr/share/plasma/plasmoids/org.forest.proxyupdater/`
(внутри — только QML, ни одного скрипта и ни одного исполняемого файла).

После установки/обновления пакета Plasma подхватывает виджет сама. Если виджета не
видно в списке — перезапустите оболочку (выход и вход в сеанс) или выполните

```sh
kbuildsycoca6 --noincremental
```

### Чтобы виджет показывал цвет состояния — одна настройка сеанса

Qt по умолчанию **запрещает** QML читать локальные файлы через
`XMLHttpRequest`, а состояние (`tray_status.json`) читается именно так (это
чтение файла, а не запуск программы). Разрешение выдаётся переменной окружения
сеанса — один раз:

```sh
mkdir -p ~/.config/plasma-workspace/env
cat > ~/.config/plasma-workspace/env/forest-proxy-updater-qml.sh <<'EOF'
export QML_XHR_ALLOW_FILE_READ=1
EOF
```

Затем **выйдите и войдите в сеанс** (или перезапустите plasmashell:
`kquitapp6 plasmashell && kstart plasmashell`). Без этой переменной виджет
безопасно показывает нейтральный серый цвет (а при явной ошибке чтения — ещё и
подсказку «состояние не читается: нужно QML_XHR_ALLOW_FILE_READ=1»); меню по
правому клику работает в любом случае.

## Как добавить значок в панель (коротко)

1. Правый клик по **свободному месту панели** → **«Добавить виджеты…»**
   (в английской локали — *Enter Edit Mode* → *Add Widgets…*).
2. В списке найдите **«FOREST Proxy Updater»** (категория «Системная
   информация»); в поиске достаточно набрать `forest`.
3. Перетащите его на панель (или нажмите «Добавить», затем выйдите из режима
   правки: **Esc** или кнопка «Выйти»).

Значок появляется в панели; цвет маленькой метки в правом нижнем углу — состояние
связи (зелёный — есть, жёлтый — идёт работа/переключение, красный — нет связи,
серый — прокси выключен, данных ещё нет или чтение файлов в сеансе запрещено).

## Кнопки

| Кнопка | Что делает |
|---|---|
| **правая** | открывает наше меню (как у значка в трее и как в Windows) |
| левая | ничего (одинаково на всех платформах) |
| **Ctrl + левая** | открывает наше меню — запасной путь |

Честно про правую кнопку: Plasma в некоторых темах/настройках оставляет правый
клик по виджету за **своим** контекстным меню («Настроить виджет», «Удалить»).
Если у вас так — меню программы открывается по **Ctrl+левому клику**; это
поведение панели, а не дефект меню. Оба пути ведут в одно и то же окно.

## Как это работает (и почему не может подвесить оболочку)

* `contents/ui/StateReader.qml` раз в **20 секунд** делает **один асинхронный**
  `XMLHttpRequest` к `tray_status.json` по `file://`. Перебираются те же пути,
  что раньше перебирал скрипт, и берётся **первый успешно прочитанный** файл:
  `$XDG_STATE_HOME/forest-proxy-updater/` → `~/.local/state/forest-proxy-updater/`
  → `/var/lib/forest-proxy-updater/state/forest-proxy-updater/` →
  `/var/lib/forest-proxy-updater/state/` → `/var/lib/forest-proxy-updater/`.
  Ничего не пишется на диск;
* если предыдущий запрос ещё не ответил, следующий тик **пропускается**; запрос,
  не ответивший за 8 секунд, бросается сторожевым таймером — «залипнуть» нечему;
* любой сбой (файла нет, битый JSON, нет прав, запрещено чтение файлов) даёт
  **пустое состояние** → нейтральный серый цвет. Исключения ловятся, наружу не
  выходят;
* **ни одного** `DataSource`, `engine: "executable"`, `Plasma5Support` и вообще
  запуска процессов в QML нет. Меню открывается так: виджет просит рабочий стол
  открыть служебный ярлык `forest-proxy-updater-menu.desktop`
  (`Qt.openUrlExternally`, `NoDisplay=true`, `Exec=… --menu-popup`) — вызов
  неблокирующий, QML никого не ждёт;
* цвета состояний — те же, что в `src/ui_style.py`; если нашей иконки нет,
  рисуется простой кружок цвета состояния (без иконочных API).

## Проверка без живого сеанса

```sh
sh plasma/plasmoid/check-plasmoid.sh
```

Скрипт делает статический аудит (ищет запрещённые конструкции и короткие
таймеры), прогоняет `qmllint` и запускает `StateReader.qml` на стенде в
offscreen-режиме на подставных файлах: валидный JSON, битый JSON, массив, число,
`null`, пустой файл, отсутствующий файл, серия кликов, а также сеанс с
запрещённым чтением файлов.

## Ограничения

* Проверено: `qmllint` (Qt 6.12, libplasma 6.8), структура пакета, стенд
  `StateReader.qml` в offscreen-режиме, отсутствие запуска процессов
  (статический аудит). **НЕ проверено** на живом сеансе Plasma: вид правого
  клика в вашей теме, внешний вид метки и открытие меню через ярлык нужно
  посмотреть глазами.
* Панели GNOME (AppIndicator) плазмоид не подходит — там остаётся значок
  `forest-ui` и меню, которое рисует расширение панели.
