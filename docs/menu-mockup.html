Это предварительный макет, а не готовая программа. Показано, как будет выглядеть и вести себя контекстное меню трея после правки: своё всплывающее окно вместо системного QMenu, потому что QMenu не умеет анимацию. Реализация в коде (src/forest_ui.py, общий модуль стиля, пересборка и обновление живой установки) начинается только после того, как макет одобрен.
Пункты — ровно как в живом дампе state/menu_dump.txt (печатает forest-ui.exe --menu-dump): ничего не пропущено и не переименовано. Галочки соответствуют дампу: «Поднимать программу автоматически» — вкл, «Уведомления» — вкл, «РФ — напрямую» — включено, «Cloudflare — обход» — включено, «Тема оформления» — «как в системе». Строка состояния сверху — пункт «только показ» (в дампе помечен так же).
Linux: при работе через системный протокол трея (StatusNotifier/AppIndicator — QSystemTrayIcon поверх него) контекстное меню рисует панель рабочего стола (KDE Plasma, GNOME, XFCE): свой вид, свои шрифты, отступы и анимация. Наш стиль там примениться не может — как и у карточки уведомления, где на Linux остаётся системное уведомление. Наш вид меню работает там, где меню рисуем мы сами (Windows и наш собственный трей без системного протокола).
Стенд: подменю показано справа от меню; на краю экрана, где справа места нет, подменю открывается влево тем же выездом (зеркальный знак сдвига). Позиция меню — по позиции курсора у значка, а не «в углу экрана».
Подпись пункта — РОВНО ОДИН слой текста (.row .lbl), цвет меняется transition: color 180ms. Прежний вариант (приглушённый слой в потоке + яркий слой поверх абсолютом со сдвигом −3 px, кросс-фейд по прозрачности) рисовал две копии подписи одновременно — это и было «двоение». Проверка числами: до правки в покое наведения 6436 чернильных пикселей (×1.90 к обычному состоянию), высота подписи 14.75 px вместо 10.75, три полосы чернил; после правки — 3791 px, 10.75 px, одна полоса, сдвиг ровно 3 CSS px.
